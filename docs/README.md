| Assignment | Milestone | Topic | Design report | Git tag |
| --- | --- | --- | --- | --- |
| 1 | M1 | Distributed OS foundation | [M1.md](assignment1/M1.md) | m1 |

Each `docs/assignmentN/` folder holds that assignment's design reports, architecture diagrams and PDFs. Results for every milestone are in `results/` (folders named M1-..., M2-..., M3-..., M4..., M5/, M6/).

To see the code exactly as it was handed in: `git checkout a1` (Assignment 1), `a2`, `a3`, or a milestone tag `m1`..`m6`. Return with `git checkout main`.
